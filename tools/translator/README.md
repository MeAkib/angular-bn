# translator

AI-assisted translation CLI (`pnpm translate`). Drafts Bangla translations of
Markdown files with the Gemini API, auto-fixes textlint/prh violations, and asks a
proofreader model to resolve the rest. Output is a draft — review it against
[GLOSSARY.md](../../GLOSSARY.md) before opening a PR.

See [docs/TRANSLATION_WITH_AI.md](../../docs/TRANSLATION_WITH_AI.md) for setup and usage.
